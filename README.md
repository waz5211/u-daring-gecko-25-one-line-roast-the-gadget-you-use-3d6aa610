## What it does

`main.ts` writes a single original one-line roast of an everyday gadget — the microwave that beeps five times when dinner is done — to `/output/entry.txt`.

## Run

```sh
node main.ts
```

It writes `/output/entry.txt` (one line, 1–200 characters, UTF-8).
